# biorill

Rust I/O libraries for bioinformatics file formats, with a focus on parsing
performance and explicit allocation and copying costs.

- `biorill-fastx`: Read, validate, edit, and write four-line FASTQ records.
- `biorill-kraken`: Read Kraken reports and select taxonomic entries.
- `biorill`: Access the format crates through optional features.
